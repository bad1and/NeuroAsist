# GEMINI / Antigravity Project Instructions

См. полные инструкции проекта и руководство по внешним инструментам (включая Inspo MCP) в файле [AGENTS.md](./AGENTS.md).

## Краткие правила:
1. **Анимации**: Всегда использовать **Anime.js v4** (`rules.md`).
2. **Дизайн**: Следовать дизайн-системе Iris (`design.md`, `tokens.css`).
3. **Inspo MCP**: При необходимости референсов для UI использовать оркестратор `recommend`, затем `get_reference_jsx` для извлечения готовых компонентов с адаптацией под цветовую палитру Iris.
