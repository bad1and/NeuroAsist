# Quality tuning — выводы

Проверка сделана на одинаковом русском тексте. Whisper-small использован только как автоматический sanity-check; тембр, естественность и похожесть голоса нужно оценить прослушиванием.

Quality-pack перегенерирован после подключения `russian-text-stresser` в изолированное окружение. Теперь русская фраза проходит через stress-разметку до токенизации: словарь даёт `Приве́т`, то есть ударение на второй слог. В повторной проверке greeting корректно распознался как «Привет, я рядом и внимательно тебя слушаю».

## Что сравнивалось

- `qwen_baya`: baseline, stable, expressive, CFG 0;
- `0718-2-clean.wav` (10,85 с): baseline;
- `0718-2-reference-5s.wav` (5,40 с): baseline;
- для двух reference дополнительно проверены greeting и normalized numbers.

## Наблюдения

| Вариант | Автоматическая проверка | Вывод |
|---|---|---|
| Qwen Baya + baseline | Диалог восстановлен почти полностью | Самый безопасный текущий reference |
| Qwen Baya + stable | Диалог восстановлен полностью | Чуть спокойнее/длиннее, не исправляет смысловые ошибки лучше baseline |
| Qwen Baya + expressive | Диалог восстановлен полностью | Быстрее и энергичнее, слушать на артефакты и темп |
| Qwen Baya + CFG 0 | Почти полный диалог, первая фраза распознана хуже | Для русского reference не нужен |
| 0718 clean 10,85 с + greeting | После greeting появились длинные несвязанные продолжения | Не использовать этот reference для коротких реплик |
| 0718 clean 10,85 с + numbers | Основной текст есть, но конец повторился | Нестабильно на технических числах |
| 0718 reference 5,40 с + greeting | Реплика в основном есть, в конце лишняя вокализация | Лучше длинного 0718, но слабее Qwen Baya |

## Практический preset

Для текущего русского Baya-подобного голоса оставлять:

```text
reference: qwen-baya-neutral.wav
exaggeration: 0.5
cfg_weight: 0.5
temperature: 0.8
repetition_penalty: 2.0
min_p: 0.05
top_p: 1.0
```

`expressive` (`exaggeration=0.7`, `cfg_weight=0.3`) можно использовать для эмоциональных реплик. `stable` — для спокойной подачи, но это не универсальный фикс качества. Числа, даты, версии, API и аббревиатуры по-прежнему нужно заранее превращать в произносимый русский текст.

Важно: ручные combining-ударения (`е́`) для этой связки не использовать. При повторной обработке страссером они дали зацикливание/растягивание короткой фразы; автоматическая разметка стабильнее.
