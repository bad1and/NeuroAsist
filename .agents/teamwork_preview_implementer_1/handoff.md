# Handoff Report: Переработка раздела История (Journal)

## 1. Выполненные требования

### R1. Двухпанельный интерфейс
- В `apps/web/src/journal.tsx` реализован двухпанельный интерфейс:
  - **Слева (`.journal-sidebar`)**: список чатов (эпизодов), загружаемых через `getTimelineJournal()`.
  - **Справа (`.journal-content`)**: область просмотра сообщений выбранного чата через `getTimelineMessages(50, episode.id)`.
  - Сообщения отображаются в виде чат-пузырей со стилями класса `.message`, с четким разделением ролей `user` (Вы) и `assistant` (Iris) и таймстемпами.
  - До выбора диалога отображается понятный плейсхолдер с предложением выбрать чат. Поддерживаются состояния загрузки и пустых диалогов.

### R2. Выделение текущего чата
- Если у эпизода отсутствует `ended_at` (`ended_at == null`):
  - Карточка эпизода в списке слева помечается классом `.is-active-episode` с зеленой акцентной полосой слева.
  - В строке заголовка карточки и в заголовке области сообщений отображается бэйдж `Текущий` / `Активен` с зеленой пульсирующей точкой (`.journal-pulse-dot`).

### R3. Мобильная адаптивность и стили
- На узких экранах (`max-width: 768px`) происходит переключение в однопанельный режим:
  - По умолчанию показывается список диалогов.
  - При клике на диалог происходит переход к сообщениям (`.journal-layout.has-selected`).
  - В шапке сообщений появляется кнопка «Назад», возвращающая пользователя к списку диалогов.
- В `apps/web/src/styles.css` добавлены необходимые CSS-классы:
  - `.journal-layout`
  - `.journal-sidebar`
  - `.journal-content`
  - `.journal-badge`, `.journal-pulse-dot`
  - `.journal-back-button`
  - `.journal-messages-container`, `.journal-message-list`

### R4. Критерии приемки (Acceptance Criteria)
- `npm run build` в `apps/web` завершается без ошибок (exit code 0).
- `npm run test` в `apps/web` завершается без ошибок: 10 тестовых файлов и 77 тестов успешно проходят.

## 2. Затронутые файлы
- `apps/web/src/journal.tsx`: новая двухпанельная реализация раздела "История" с поддержкой загрузки сообщений эпизода, активных бэйджей и мобильной навигации.
- `apps/web/src/styles.css`: стили для двухпанельного лейаута, сайдбара, контента, сообщений, пульсирующего индикатора и мобильных медиа-запросов.
- `apps/web/src/ui.test.tsx`: модульные тесты для двухпанельного интерфейса, загрузки сообщений, выделения активного чата, мобильной кнопки "Назад" и поиска.
- `apps/web/src/App.tsx`, `apps/web/src/components/CustomSelect.tsx`, `apps/web/src/state.test.tsx`: сопутствующие исправления для стабильного прохождения полного набора тестов в Vitest/JSDOM.
