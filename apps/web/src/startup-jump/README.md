# Мини-игра на экране запуска Iris

Мини-игра подключена к рабочему `StartupScreen`.
Макет `/startup-game-preview.html` использует тот же компонент и стили.

Фигурка и платформы находятся прямо на фоне загрузки, без отдельной поверхности,
рамки, счёта, видимых надписей и элементов управления. Кубик повторяет сиреневый
материал кнопок Iris: мягкий блик, градиентная светящаяся кромка и короткий ореол.
Платформы имеют точную заливку силуэтов логотипа: белый с прозрачностью 0.075.
Видимая область 248 × 159 px; в невысоких окнах она уменьшается.
Композиция логотипа и текста всегда по центру окна. Игра закреплена отдельно
внизу и не сдвигает композицию. Сначала доступна текстовая кнопка «Попинать х..» без подложки;
по нажатию игра монтируется и запускается, клавиатурный фокус переходит к ней.

Прыжки автоматические. Управление стрелками, физическими клавишами A/D
(в том числе в русской раскладке) или удержанием пальца слева/справа от кубика.
Нажатие на сцену или пробел запускает и возобновляет игру.
Escape ставит игру на паузу. Потеря фокуса и скрытие вкладки тоже ставят её
на паузу; продолжение требует нажатия. После падения можно начать заново.

Один Canvas 336 × 216, плотность пикселей ограничена 1.5. Anime.js v4 запускает
цикл с частотой 30 кадров/с только во время игры. Физика меняет обычный объект,
Материал и свечение кубика заранее запекаются в один небольшой Canvas-спрайт;
во время игры React обновляет только состояния паузы и завершения. Платформы переиспользуются
в пределах небольшого списка. Долгий кадр не вызывает тяжёлого наверстывания.
Новые зависимости и медиафайлы не нужны. При reduced motion отключён длинный
переход появления; игровое движение начинается только по явному нажатию.

Служебные кнопки доступны по адресу `/startup-game-preview.html?controls=1`.
Кнопки «Готово» и «Ошибка» позволяют проверить завершение игры: готовность
останавливает цикл сразу, затем существующая анимация переводит экран в
демонстрационную заглушку. При ошибке игра скрывается, доступен повторный запуск.
Макет не обращается к backend и не имитирует его прогресс таймером.

Компонент загружается отдельным lazy-чанком только после нажатия «Попинать х..».
Он доступен при запуске ядра и при ожидании модели/голоса после готовности ядра.
Готовность всех сервисов (status ready, stage 3) сразу размонтирует игру,
не ожидая окончания партии или финальной анимации лепестков. Ошибка и закрытие
тоже размонтируют её. Новый запуск снова показывает кнопку.
Финал логотипа и переход к приложению используют существующую логику.
Фактическое влияние на холодный запуск desktop ещё не измерено.

Проверки: `npm test -- src/startup-jump/world.test.ts src/startup-jump/StartupJump.test.tsx`
и `npm run build` в `apps/web`.
