# Материалы главного README

Снимки сняты 9 октября 2026 года с текущего рабочего дерева Iris 1.0.0.
Снято настоящее окно приложения Windows: Tauri, локальное FastAPI-ядро
и подключённый Unity-аватар в режиме «внутри приложения».
Эталонный размер окна — 1135 × 760 логических px: штатная настройка
«зафиксировать эталонный размер» включена через Tauri. Область снимка —
1135 × 760 px, масштаб WebView2 — 100%, масштаб дисплея — 100%,
язык — русский, тема — штатная графитовая. Захвачена видимая область окна
через Windows, включая отдельную поверхность Unity. Интерфейс для съёмки не менялся.

История и память подготовлены в отдельной временной базе через `TimelineStore`.
Реплики на снимках — примеры для оформления, а не результаты запросов к модели.
Личные данные, ключи и настройки владельца проекта не использовались.
Tauri получает ключи штатным способом через Credential Manager; значения
не считывались для съёмки и не записывались в файлы. Запросы к модели не отправлялись.
Предзагрузка STT/TTS, семантический поиск и фоновое извлечение памяти отключены.
Unity-аватар реально подключён и виден в диалоге. Статусы API не подменялись.
Снимки показывают интерфейс и встроенный аватар. Они не подтверждают качество
ответов модели, голосовой режим или готовность Windows-установщика.

Каждая правая веточка — точное горизонтальное отражение левой. Изменения
ограничены пропорциональным масштабированием, компоновкой и плавным затуханием
альфа-канала у среза стеблей и внешнего края. Исходные файлы не менялись.
Фон прозрачен; светлая и тёмная версии различаются цветом текста и штатной
редакцией логотипа. Подписи переведены, существенная информация и навигация
остаются обычным текстом README. Сгенерированное ранее украшение удалено.

Сборка — [scripts/build_readme_art.py](../../../scripts/build_readme_art.py),
Pillow. Перед запуском существующие `iris-wordmark-light.svg` и
`iris-wordmark-dark.svg` рендерятся браузером в прозрачные PNG шириной 600 px
под именами `logo-light.png` и `logo-dark.png` в отдельном рабочем каталоге;
затем этот каталог передаётся скрипту через `--logo-dir`. Шрифт — штатный
Windows Segoe UI. Итоговые PNG: 1800 × 620 и 1800 × 380; в README показаны
шириной до 900 px через GitHub-совместимый `<picture>`.
Текст на постерах является частью изображения, а не описанием прав доступа
или контрактов приложения.
