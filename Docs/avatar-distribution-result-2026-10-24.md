# Раздельная сборка: результат 24 октября 2026 года

Основа готова в публичной ветке
[`v0.9.1`](https://github.com/bad1and/NeuroAsist/tree/v0.9.1).
Версия продукта остаётся `1.0.0`. Закрыто собирается только Unity;
публичный workflow собирает каталог приложения из открытого кода и готового
Player. Установщик и GitHub Release на этом этапе не создавались.

## Что сделано

- Создан закрытый `Gogowski/NeuroAsist-avatar-private`. Материалы перенесены
  с проверкой SHA-256; `bad1and` приглашён с правом записи.
- Существующий `bad1and/NeuroAsist` остался публичным, с прежним адресом.
  Обычные ветки обновлены после фильтрации в отдельном mirror. Полная исходная
  история, рабочие файлы и соответствия старых/новых commits сохранены локально.
- Из истории исключены 73 объекта частных материалов. Проверены 299 commits:
  остальные файлы, их режимы и содержимое сохранены; commits не удалялись.
  SHA изменились там, где этого требует переписывание истории.
- В `main` добавлена точка ручного запуска workflow. Сам код собирается
  по явно указанному полному SHA из проверенной ветки.
- Пакет Player проверяется по независимому SHA-256, digest исходников Unity,
  перечню и хешам файлов. Исходные модели, небезопасные пути и лишние файлы
  отклоняются. Новые публичные изменения проверяет CI без доступа к секретам.

## Инструкция второму разработчику

1. Принять приглашение в закрытый репозиторий. Продолжать работу из свежего
   clone `v0.9.1`. Старый checkout содержит прежнюю историю: его нельзя пушить
   или сливать обратно. Локальные несвязанные изменения переносятся отдельно.
2. В настройках **закрытого** репозитория добавить Windows self-hosted runner
   с меткой `iris-avatar-private`. Установить и активировать Unity 2022.3.62f3
   с Windows Build Support (Mono); указать путь через переменную окружения
   `NEUROASIST_UNITY_EDITOR`, доступную процессу runner. Нужны PowerShell 7,
   Git и Python 3.12. Подключать этот runner к публичному проекту не следует.
3. Создать отдельный fine-grained token владельца `Gogowski`: доступ только
   к `NeuroAsist-avatar-private`, разрешение **Actions: read**. Добавить его
   в Secrets публичного `bad1and/NeuroAsist` под именем
   `IRIS_AVATAR_ARTIFACT_READ_TOKEN`. Сам токен в переписку не отправлять.
4. Настроить environment `release-candidate` в публичном репозитории:
   ограничить запуск проверенными разработчиками и проверенными refs.
   Проверить изменения workflow перед выдачей ему секрета.
5. В закрытом Actions вручную запустить `Build private Iris Unity Player`
   с полным 40-символьным SHA проверенного кода `v0.9.1`. Из успешного запуска
   сохранить run ID и независимо сверенный SHA-256 внутреннего
   `iris-avatar-windows.zip`. Скачанный внешний Actions ZIP — другой архив.
6. В публичном Actions запустить `Build Windows application candidate`:
   указать SHA приложения, закрытый run ID и хеш Player. Результат — artifact
   с каталогом приложения без NSIS. Проверить запуск Iris, встраивание Unity,
   голос и состав поставки. Установщик готовится отдельным этапом.

Artifacts хранятся 30 дней. Перед будущим выпуском нужен долговременный
проверенный компонент. Изменение Unity-кода или протокола требует нового
Player; документация и независимый код приложения digest не меняют.

## Что ещё мешает полному удалению модели

Свежий обычный clone чист, но старые доступные только для чтения
`refs/pull/*` GitHub всё ещё содержат VRM. Обычный force push их не очищает;
пока нельзя обещать, что исходник невозможно скачать. Владельцу публичного
репозитория нужно обратиться в GitHub Support по оставшимся PR refs и кэшу.
Локально подготовлен черновик обращения и отчёты; обращение не отправлялось.
Процедура удаления секретов не гарантирует удаления материалов такого типа.
[Ограничения GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).

Упаковка Unity затрудняет извлечение ресурсов, но не гарантирует его
невозможность. Разрешение автора на выбранную форму поставки и остальные
условия выпуска учитываются отдельно в [реестре компонентов](distribution-components.json).
