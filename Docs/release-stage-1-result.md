# Iris — результат первого этапа

Дата: 20 октября 2026 года. Основание — [согласованный план](release-stage-1-plan.md).

Исправления восьми пунктов внесены, автоматические проверки завершены успешно.
Ручная приёмка в настоящем окне Windows остаётся отдельным шагом. Дизайн, размеры и расположение
элементов сохранены. Личная история, память, ключи и прежние сборки не заменялись.

## Что изменено

| Пункт | Результат |
| :--- | :--- |
| Coding Agent | Старые ответы загрузки и завершившиеся действия не переключают новую выбранную задачу. Применение, остановка, повтор и указания доступны после загрузки правильной задачи. |
| Документы | Текст фрагментов передаётся модели, но не сохраняется скрыто в новых метаданных SQLite/ZIP. История содержит ответ и сведения об источниках. Недоступный исходный текст поясняется в существующем интерфейсе. |
| Напоминания | Исправлены даты вида «23-го», RU/EN, относительное время, полночь, границы месяца/года и смещения UTC. Неоднозначность вызывает уточнение. Подтверждение берёт сохранённый срок; повтор не возрождает отменённую запись. |
| Ошибки запуска | Все возвращаемые ошибки запуска ядра проходят через единый обработчик: состояние failed, причина, повтор и доступное восстановление. |
| Safe Mode | Оболочка остаётся единственным экземпляром; перезапускаются её управляемые процессы. Прогрев речи и загрузка embedding-модели пропускаются, Unity отключён. |
| Проверки остановки | Оба smoke-сценария требуют код выхода 0. Проверены настоящими PowerShell-сценариями с контрольными HTTP-процессами, завершающимися с 0 и 7. |
| Перевод окон | Перевод охватывает порталы вне основного контейнера, включая новые окна. Названия настроек переводятся; пользовательские планы, реплики и исходный текст защищены от перевода. |
| Память и планы | Поиск передаётся темам и планам; напоминания учитывают тот же поиск. Выбранная сортировка больше не заменяется сортировкой по сроку. |

Для неоднозначного «завтра в двенадцать ночи» Iris уточняет срок. Точная дата
с `00:00` однозначна. Повторяющиеся напоминания в этот этап не добавлялись.

## Что ещё требует настоящего окна Windows

Открыты переход через меню трея в Safe Mode, повтор после искусственного отказа
доступа/хранилища ключей в Tauri и проверка всех окон с реальным DPI и Unity.
Проверки состояния, параметров запуска и ядра не заменяют эти сценарии.
Их нужно подтвердить на новом каталоге приложения перед установщиком.

Старая история и ZIP могут содержать ранее сохранённые исходные фрагменты
документов. Они автоматически не очищались; это отдельно описано в политике
конфиденциальности. Самостоятельную очистку существующих данных этот этап не вводит.

Следующий этап: зависимости и security-разбор, включая pypdf в release-среде,
права поставки, затем общая актуализация релизных документов и свежий кандидат.
