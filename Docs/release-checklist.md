# Проверки перед выпуском

**Релиз не одобрен.** Отметки ниже заполняются для конкретного commit, тега и
установщика. Успешная разработческая сессия или сборка исходников не заменяют
проверку поставляемого приложения.

Создайте [карточку сборки](release-evidence.md), приложите подтверждения к
каждому разделу и выполните [порядок выпуска](release-runbook.md).
Пункт без отчёта остаётся открытым. Если проверка неприменима, запишите причину
и решение ответственного за выпуск.

## 01 · Исходники и версия

- [ ] `VERSION`, npm, Cargo, Tauri, FastAPI и Unity согласованы.
- [ ] `scripts/check_docs.py` проверяет метаданные, параметры окружения и локальные ссылки.
- [ ] Проверяемый commit находится в чистом рабочем дереве; тег равен `v` + `VERSION`.
- [ ] Примечания к версии описывают изменения, миграции и ограничения.
- [ ] Сборка воспроизводится из нового клона по документированным командам.

Подтверждение: commit, тег, журнал проверки документации и сборки из нового клона.

## 02 · Автоматические проверки

- [ ] Полный набор backend-тестов прошёл.
- [ ] Vitest, TypeScript/Vite production build и Rust `cargo check` прошли.
- [ ] Проверка управляемого ядра подтверждает авторизацию и корректную остановку.
- [ ] Проверка упакованного ядра прошла на поставляемом исполняемом файле.
- [ ] В ресурсах сборки нет ключей, `.env`, пользовательской SQLite и диагностического аудио.
- [ ] Ключи диалога, Coding Agent и поиска вводятся через приложение и хранятся раздельно в Credential Manager.
- [ ] В Python-ядре нет удалённых прямых зависимостей и пакетов экспериментов.
- [ ] GitHub `CI` и `Documentation` прошли на проверяемом commit.
- [ ] `Synthetic lifecycle soak` выполнил одночасовой профиль с порогом роста RSS.

Подтверждение: ссылки на CI, журналы проверки ядра, ресурсов и отчёт прогона.
Команды — в [эксплуатации](operations.md#проверки-изменений).

## 03 · Ответы, поиск и расход LLM

- [ ] Обычные назначения chat/live/memory/reflection/adjudication не расходуют reasoning tokens.
- [ ] Основной ответ использует один логический вызов; служебные поисковые вызовы учтены отдельно.
- [ ] Физические повторы ниже 2% в контрольной сессии; исправления ответов не создают бесконечных повторов.
- [ ] Все назначения имеют конечный `max_tokens`; рассуждение Coding Agent учитывается отдельно.
- [ ] Видны токены ввода/вывода, попадания в кэш, физические попытки и задержки.
- [ ] Консолидация памяти соблюдает условия запуска и снижает расход относительно исходного измерения.
- [ ] 30-минутный контрольный диалог укладывается в заранее записанный бюджет.
- [ ] Поисковые ответы различают обращение к источнику, кэш, пустую выдачу, ошибку и некорректный запрос.
- [ ] Источники и прочитанные страницы отражены в истории; запрет интернета и отмена соблюдаются.
- [ ] Поисковые уведомления по умолчанию выключены; реплика ожидания появляется только при задержке.

Подтверждение: обезличенная телеметрия и набор диалоговых сценариев с результатами.

## 04 · Память и персонаж

- [ ] Проверочный корпус подтверждает просьбы запомнить, исправления, предпочтения, цели и важные события.
- [ ] Обычная беседа и повтор известного факта не создают лишние задания консолидации.
- [ ] Чувствительные сведения обрабатываются по выбранной политике.
- [ ] Сжатие контекста сохраняет характер, обработку исправлений и корректность структурированных ответов.
- [ ] Редактирование, архивирование и удаление памяти отражаются в поиске и аудите.
- [ ] Семантический индекс восстанавливается из SQLite без потери канонической памяти.

Подтверждение: отчёт проверки памяти и персонажа с версией корпуса и порогами.

## 05 · Голос и аватар

- [ ] Не менее часа реального голосового разговора без остановки исполнителей, старых ответов и неконтролируемого роста памяти.
- [ ] Разрыв и переподключение во время STT, LLM и TTS не публикуют старый результат.
- [ ] Обычная остановка завершает подтверждённую реплику; разрыв отменяет её задачи.
- [ ] Перебивание отменяет только текущий ответ и не затрагивает новый.
- [ ] Фоновый шум не вызывает ложных реплик на проверяемом микрофоне.
- [ ] Записаны задержки первого текста и звука после первого и повторного запуска.
- [ ] Для `voice.end_of_speech_to_playback` записаны P50/P95; целевой P95 ≤ 2,5 с.
- [ ] Оба размещения Unity-аватара прошли длительный тест синхронизации речи, жестов и остановки процессов.

Подтверждение: оборудование, акустические условия, длительность и отчёт.
Синтетический CI-прогон не закрывает этот раздел.

## 06 · Данные и восстановление

- [ ] Миграция копии данных предыдущей поддерживаемой версии проходит.
- [ ] До изменения схемы создаётся резервная копия.
- [ ] ZIP цел и не содержит ключей.
- [ ] Проверенное восстановление возвращает историю, память и настройки на чистой установке.
- [ ] Повреждённая база даёт понятную ошибку и не заменяется пустой.
- [ ] Очистка истории, памяти и состояния персонажа соблюдает заявленные границы.
- [ ] Удаление приложения предоставляет осознанный выбор сохранения пользовательских данных.

**Открыто:** создание, список и удаление резервных копий реализованы,
восстановления через интерфейс нет. Для релиза нужна реализованная функция
или проверенная пользовательская процедура.

Подтверждение: исходная версия данных, результаты миграции, проверки SQLite и восстановления.

## 07 · Установщик на чистой Windows

- [ ] NSIS устанавливает приложение без Python, Node.js, Rust и команд терминала.
- [ ] Название, издатель, версия и идентификаторы верны в установщике и бинарных файлах.
- [ ] Первый запуск, ввод ключа и повторный запуск работают.
- [ ] Безопасный режим доступен при неисправном Unity или загрузке моделей.
- [ ] Загрузка моделей показывает размер, прогресс, проверку целостности, повтор и удаление.
- [ ] Расчётный минимум из README проверен на соответствующем ПК: первый запуск, реальный голос, свободное место и память при длительной работе; неподтверждённые оценки явно обозначены.
- [ ] Поведение без интернета после загрузки моделей понятно и проверено.
- [ ] Базовая сборка не обещает CUDA без отдельно поставленного и проверенного GPU runtime.
- [ ] Обновление сохраняет данные и не дублирует автозапуск или регистрацию экземпляра.
- [ ] Удаление завершает процессы и удаляет файлы приложения в заявленных пределах.
- [ ] Доставка WebView2, системных библиотек и FFmpeg/FFprobe проверена.

Подтверждение: образ Windows, сценарии установки/обновления/удаления и их результаты.
Ориентиры и эталон — в [системных требованиях](system-requirements.md).

## 08 · Безопасность, данные и лицензии

- [ ] Управляемое ядро принимает запросы только с временным токеном.
- [ ] Секреты отсутствуют в журналах URL, настройках, ZIP, отчётах сбоев и событиях.
- [ ] Coding Agent использует Docker без сети, оболочки хоста и живого подключения проекта.
- [ ] Изменение исходного файла после снимка блокирует применение конфликтующей правки.
- [ ] Проверены лицензии зависимостей, весов, Unity/VRM/Mixamo и бинарных компонентов.
- [ ] Для `IRIS.vrm` подтверждены права на AI-сценарий и распространение; ограничения автора и `Redistribution_Prohibited` разобраны.
- [ ] Ограничение AI/ML в условиях Mixamo проверено для фактического использования и поставки Iris.
- [ ] Обязательные уведомления о лицензиях включены в поставку.
- [ ] Политика конфиденциальности описывает внешний LLM, веб-поиск и локальную обработку речи.

Подтверждение: перечень компонентов с версиями, условиями поставки и результатом проверки.

## 09 · Решение о выпуске

- [ ] Все обязательные проверки подтверждены.
- [ ] Ограничения опубликованы в примечаниях к версии.
- [ ] SHA-256 установщика совпадает с манифестом и публикуемой контрольной суммой.
- [ ] Манифест содержит commit, размер, результат проверки ресурсов до NSIS и статус подписи.
- [ ] Подготовлены предыдущая сборка и процедура отката с сохранением данных.
- [ ] Ответственный за выпуск явно одобрил публикацию.

Если открыта проверка данных, секретов, установки или жизненного цикла,
сборка остаётся внутренним кандидатом.
