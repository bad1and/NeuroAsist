# Раскрывающиеся блоки Iris

Для встроенных раскрывающихся разделов используй `Disclosure` из
`apps/web/src/components/Disclosure.tsx`. Это общий стандарт для технических
данных, подробностей, журналов, источников и вложенных списков.

В закрытом состоянии видны текст и контрастная стрелка 20 px. Графитовая
подложка появляется при наведении, нажатии и фокусе с клавиатуры; у открытого
раздела она остаётся после ухода курсора. Повторное нажатие сворачивает раздел.
Радиус и форма берутся из `--radius-control` и `--corner-shape`.
Капсульный радиус `999px`, браузерный треугольник и отдельные варианты
оформления для каждой страницы не нужны.

Стрелка и высота содержимого анимируются через Anime.js v4 с учётом
`prefers-reduced-motion`. Текст и область нажатия не перемещаются вместе
с декоративным материалом. Закрытые поля сохраняют черновики, но исключены
из навигации клавиатурой и дерева доступности.

```tsx
import { Disclosure } from "./components/Disclosure";

<Disclosure materialKey="system.technical" label="Технические данные системы">
  <SystemInfo />
</Disclosure>
```

`defaultOpen` задаёт только начальное состояние. Если раздел нужно раскрывать
из поиска, фильтра или другого действия, используй управляемые `open` и
`onOpenChange`. Существующие открытые по умолчанию журналы и просмотры diff
сохраняют это поведение.

```tsx
<Disclosure materialKey="requests.journal" label="Подробный журнал запросов"
  open={journalOpen} onOpenChange={setJournalOpen}
  contentClassName="request-records" regionLabel="Журнал запросов">
  <RequestRecords />
</Disclosure>
```

`materialKey` должен быть стабильным для действия; в списках включай в него
идентификатор записи. `contentClassName` оформляет внутреннее содержимое,
`className` — внешнее размещение. Не переопределяй материал и геометрию
кнопки в CSS страницы. `contentId` задаёт известный идентификатор панели;
обычно компонент создаёт уникальные идентификаторы сам. `regionLabel`
добавляет именованную область там, где она нужна для ориентации.

Дополнительные действия заголовка передавай через `actions`. Они будут
соседями кнопки раскрытия: вложенные кнопки внутри `label` недопустимы.
Названия файлов и пользовательский текст в `label` сохраняют `data-i18n-skip`.

Если страница уже управляет собственной панелью, используй
`DisclosureTrigger` с `open` и `aria-controls`. Это тот же материал,
стрелка и клавиатурное поведение, без второй обёртки вокруг содержимого.

Новые встроенные аккордеоны не создаются через отдельные `<details>` /
`<summary>` или копию `MaterialButton` со своим `aria-expanded`.
Меню действий, `CustomSelect`, поисковый combobox, редактор сочетаний клавиш
и навигационные группы имеют другую семантику и сохраняют свои компоненты.
Существующий `memory-action-menu` — меню действий, а не раскрывающийся раздел.

Проверяй раскрытие с Enter и Space, повторное закрытие, сохранение черновиков,
вложенные разделы, переходы из поиска и контраст стрелки на узком экране.
