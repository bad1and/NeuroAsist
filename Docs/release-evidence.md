# Карточка проверяемой сборки

Шаблон для отдельного кандидата. Скопируйте его в каталог подтверждений вашего
релиза; этот файл не является заполненным отчётом. Замените «не заполнено»
фактическими значениями. Личные журналы и базы в публичный репозиторий не входят.

## Паспорт

| Поле | Значение |
| :--- | :--- |
| Версия / тег | Не заполнено |
| Commit SHA | Не заполнено |
| Дата и ответственный | Не заполнено |
| Runner / образ Windows | Не заполнено |
| Python / Node.js / npm / Rust / Unity | Не заполнено |
| CPU / RAM / GPU / VRAM / свободный диск | Не заполнено |
| Профиль требований: расчётный минимум / рекомендация / эталон | Не заполнено |
| Установщик / размер / SHA-256 | Не заполнено |
| Манифест / подпись | Не заполнено |

## Проверки

| Область | Результат | Подтверждение и условия |
| :--- | :--- | :--- |
| Документация и версия | Не выполнено | Не заполнено |
| Backend / Web / Rust | Не выполнено | Не заполнено |
| Управляемое и упакованное ядро | Не выполнено | Не заполнено |
| Синтетический часовой прогон | Не выполнено | Не заполнено |
| Чистая установка / обновление / удаление | Не выполнено | Не заполнено |
| Миграция / ZIP / восстановление / повреждённая база | Не выполнено | Не заполнено |
| Реальный голос и оба размещения аватара | Не выполнено | Не заполнено |
| Память / персонаж / стоимость | Не выполнено | Не заполнено |
| Поиск / кэш / отмена / продолжение новостей | Не выполнено | Не заполнено |
| Секреты / лицензии / подпись | Не выполнено | Не заполнено |

Допустимые результаты: «пройдено», «не пройдено», «не выполнено»,
«не применимо — причина». Для каждого пункта сохраняйте сценарий, ожидаемый
результат, фактический результат и ссылку на отчёт.

## Голосовая сессия

- Микрофон, устройство вывода и акустика: не заполнено.
- CPU, GPU, память и речевой профиль: не заполнено.
- Модели и revisions, первый/повторный запуск: не заполнено.
- Длительность, число реплик, перебивания и переподключения: не заполнено.
- P50/P95 последней речи → фактического воспроизведения: не заполнено.
- Начальный/конечный RSS, рост и ошибки: не заполнено.

## Ограничения и откат

Перечень известных ограничений: не заполнено.

Предыдущая проверенная сборка, совместимость данных и предмиграционная копия:
не заполнено.

## Решение

**Не одобрено: карточка не заполнена.**

Ответственный, дата, решение и ссылки на закрытые
[условия публикации](release-checklist.md): не заполнено.
