# Milestone 9 — Live Voice, VAD и Barge-in

## Что работает

- Режим свободных рук включается пользователем вручную и передаёт PCM16 в input WebSocket без сохранения постоянного файла записи.
- Browser AudioWorklet и backend VAD подтверждают начало речи после короткого антишумового порога; до подтверждения случайный шум не перебивает ответ.
- После паузы VAD формирует одну реплику, отправляет её на STT и запускает обычный live-ответ.

## Перебивание ассистента

Подтверждённое начало пользовательской речи вызывает один barge-in на реплику:

```text
VAD: speech_started
  → немедленно остановить live queue / WAV / browser speech в UI
  → voice.cancel через WebSocket (REST fallback при отсутствии канала)
  → отменить live LLM и сегментный TTS
  → отменить незавершённый full-WAV TTS текущей session_id
  → avatar.stop для Unity
  → продолжить запись пользовательской реплики
```

Нажатие push-to-talk во время ответа использует тот же путь до открытия микрофона. Уже созданный WAV не обязательно удаляется сразу: он безопасно остаётся в кратковременном TTS-кэше и будет убран штатной очисткой, но больше не воспроизводится.

## Ограничения

- Это не always-on режим: свободные руки остаются выключенными, пока их не включит пользователь.
- Echo cancellation и anti-noise debounce уменьшают ложные перебивания, но их чувствительность зависит от микрофона, колонок и системных настроек Windows.
