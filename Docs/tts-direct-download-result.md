# TeraTTS: прямая загрузка пользователем

Реализовано 21 октября 2026 года в исходниках Iris.

## Как работает

1. Пользователь нажимает **Скачать** в существующей карточке модели и
   подтверждает выбранную папку.
2. Iris получает файлы напрямую из репозитория автора на Hugging Face
   (с перенаправлениями на CDN платформы), проверяет SHA-256 и сохраняет их
   в хранилище моделей пользователя. Отмена и повтор загрузки сохранены.
3. В карточке доступны необязательные ссылки **Источник модели** и
   **Условия использования**. Дополнительных окон при запуске нет.

Версия TeraTTS и хеши файлов сохранены. Каталог отклоняет подмену закреплённых
адресов на зеркало или изменяемую ветку. Desktop открывает только ссылки из
встроенного каталога, а не произвольный адрес из интерфейса.

## Что защищает сборку

Проверка перед Tauri/NSIS отклоняет TeraTTS snapshot, кэш и известные веса,
включая переименованные файлы. Проверяются ресурсы ядра, аватара и legal.
Повторная проверка AppOnly охватывает весь каталог приложения. Тексты notices
и остальные библиотеки ONNX допускаются.

Модель не переносилась в установщик и не выкладывалась на наш сервер.
Существующее хранилище пользователя не изменялось.

## Проверено

- 38 проверок менеджера моделей, API и состава сборки прошли.
- Полный backend-прогон: 1382 прошли, один тест Coding Agent упал из-за гонки
  с настоящим фоновым исполнителем при отсутствии Docker. В тесте изолирована
  фоновая обработка; повторная проверка всего модуля Coding Agent и новых
  проверок моделей — 49 прошли. Общий прогон после этого повторно не запускался.
- Интерфейс: 366 тестов прошли; финальная проверка карточки — 9 тестов.
  Production-сборка веб-интерфейса прошла.
- Desktop: 17 тестов прошли, 1 ручная проверка окна пропущена.
- Реальная загрузка через Model Manager: README, RUAccent notice и небольшой
  голосовой файл из официального snapshot — 3 файла, 6996 байт; хеши совпали.
  Использовалось отдельное тестовое хранилище.
- Проверка имеющихся ресурсов ядра/аватара и third-party прошла;
  синтаксических ошибок в PowerShell-сценарии сборки нет.

Полную модель заново не скачивали. Открытие системного браузера, настоящий
голосовой разговор и новый установщик в этой работе вручную не проверялись.
Логи сохранены в `output/tts-direct-download-20261021/`.

## Что остаётся

Отдельная сборка FFmpeg и проверка конкретных условий использования TeraTTS
остаются в [плане поставки](tts-ffmpeg-delivery.md). Письмо автору не отправлялось;
его отсутствие само по себе не объявляется запретом прямой загрузки.
Реестр компонентов сохраняет открытый статус проверки прав, без автоматического
разрешения на публичный выпуск.
