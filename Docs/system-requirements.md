# Системные требования и расчёт ресурсов

Требования относятся к Iris 1.0.0 из исходников: GigaAM v3 RNNT ONNX FP32,
TeraTTSv2 `ru_f1` на CPU, Silero VAD, Smart Turn и внешняя модель диалога.
Локальная LLM в этот расчёт не входит. Краткая таблица — в
[README](../README.md#системные-требования); инструменты и команды установки —
в [зависимостях](dependencies.md).

## Минимум и рекомендация

| Ресурс | Минимальный ориентир | Рекомендация |
| :--- | :--- | :--- |
| ОС | Windows 10 22H2 x64 | Windows 11 x64 |
| CPU | 4 ядра / 8 потоков с AVX2 | Ryzen 7 5700X, 8 ядер / 16 потоков |
| ОЗУ | 8 ГБ, около 5 ГиБ свободно перед запуском | 16 ГБ для обычного разговора |
| GPU | Встроенная графика для интерфейса, STT/TTS на CPU | GTX 1660 SUPER 6 ГБ для аватара и необязательного CUDA STT |
| Диск | 20 ГиБ свободно под запуск из исходников | 30 ГиБ на SSD |

Минимум — оценка для голоса **без Unity-аватара и Docker**, а не результат
испытаний на слабом ПК. Четырёхъядерный CPU, 8 и 16 ГБ ОЗУ отдельно не
проверялись. AVX2 выбран как консервативный ориентир для CPU-вычислений,
а не установленная экспериментом граница совместимости. Windows ARM64, Linux и macOS как настольные
поставки Iris не квалифицированы.

## Эталонный компьютер

Компьютер разработчика, на котором запускали Iris и проводили локальные
измерения. Характеристики повторно сняты **12 октября 2026 года**:

| Компонент | Фактическая конфигурация |
| :--- | :--- |
| CPU | AMD Ryzen 7 5700X, 8 физических ядер / 16 потоков |
| ОЗУ | 32 ГБ установленной памяти; Windows видит около 31,93 ГиБ |
| GPU | NVIDIA GeForce GTX 1660 SUPER, 6144 МиБ видеопамяти |
| ОС | Windows 11 Pro x64, сборка 26200 |
| Драйвер NVIDIA | 617.14 на дату сверки |

Рекомендованные 16 ГБ — расчётное снижение относительно эталонных 32 ГБ.
Драйвер указан для воспроизводимости среза, а не как обязательная версия.
Старые STT-измерения использовали другой драйвер; их условия остаются в
[датированном отчёте](stt-comparison.md#условия-и-методика).

## Откуда взялась оценка ОЗУ

12 октября выполнен отдельный офлайн-прогон уже скачанных моделей. В одном
Python-процессе загружены GigaAM ONNX на CPU и TeraTTSv2 с полным RUAccent,
выполнены прогрев, синтез короткой фразы и распознавание полученного WAV.
Основное приложение, пользовательская база и API-ключи не использовались.

| Стадия | RSS процесса |
| :--- | ---: |
| Импорт библиотек | 200 МиБ |
| После загрузки GigaAM CPU | 1104 МиБ |
| GigaAM и TeraTTSv2 после прогрева | 3151 МиБ |
| После синтеза и распознавания | 3175 МиБ — около 3,1 ГиБ |

RSS снимался также каждые 20 мс; наибольший наблюдаемый результат —
3175 МиБ. Это короткая проба речевых провайдеров, **не** пик полной Iris:
в неё не входят React/WebView2, Unity, Chroma, длительная история и Docker.
Для интерфейса, ядра и колебаний нагрузки заложен запас до примерно 5 ГиБ
свободной памяти перед запуском. Вместе с Windows получается тесный
ориентир 8 ГБ; 16 ГБ оставляет значительно больше места для обычной работы.

Проба использовала 8 ONNX-потоков STT, 8 потоков TeraTTS и профиль
PyTorch 4 intra-op / 1 inter-op. Она не доказывает ту же скорость на
четырёхъядерном компьютере. Для проверки минимальной конфигурации ещё нужен
полный разговор с микрофоном и наблюдение памяти после длительной работы.

## Место на диске

Размеры сверены по локальным файлам закреплённых revisions. Символьные
ссылки Hugging Face на те же blobs не посчитаны второй раз.

| Модели | Размер |
| :--- | ---: |
| GigaAM v3 RNNT ONNX FP32, выбранные RNNT-файлы | Около 849 МиБ |
| TeraTTSv2, snapshot с RUAccent и голосами | Около 1118 МиБ |
| Silero VAD и Smart Turn | Около 10,4 МиБ |
| Всего | Около 1,93 ГиБ |

20 ГиБ — бюджет для текущего запуска из исходников, а не размер установщика.
Кроме моделей нужны Python-окружение, npm-пакеты, Rust-сборка оболочки,
кэши скачивания и временные файлы. CUDA STT добавляет библиотеки NVIDIA:
на эталоне их каталог занимает около 2,2 ГиБ, отдельно от ONNX Runtime.
SSD ускоряет загрузку весов; HDD отдельно не испытывался.

Python, Node.js, Rust, Microsoft C++ Build Tools, Unity Editor и его `Library`,
Docker/WSL, образы контейнеров и повторные release-сборки требуют места
**сверх** таблицы. История, аудиокэш, ZIP-копии и задания тоже растут;
их объём зависит от использования. Если репозиторий и `%LOCALAPPDATA%`
на разных дисках, оставьте не менее 5 ГиБ на диске моделей и остаток бюджета
на диске проекта. Не переносите пользовательские данные при работающей Iris.

## Дополнительные компоненты

- **Аватар.** В новом клоне его нужно собрать Unity 2022.3.62f3 с модулем
  Windows Build Support (Mono). GTX 1660 SUPER 6 ГБ — проверенный аппаратный
  ориентир, нижний предел GPU для аватара не измерен. Сам Unity Editor
  не нужен во время обычного запуска готового аватара.
- **CUDA STT.** Нужны совместимые GPU и драйвер NVIDIA, профиль
  `requirements/stt-cuda.txt`. PyTorch CUDA не заменяет GPU ONNX Runtime;
  TeraTTS остаётся на CPU. Совместимость CUDA/cuDNN описана в
  [документации ONNX Runtime](https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html).
  6 ГБ — конфигурация эталона, не доказанный минимум видеопамяти.
- **Coding Agent.** Нужны Docker Desktop и отдельный API-ключ. Контейнер
  по умолчанию ограничен 2 CPU и 2048 МиБ RAM; виртуальная машина Docker/WSL
  и образы требуют дополнительного запаса. 32 ГБ разумны при совмещении
  Iris, Docker, редактора Unity и других тяжёлых приложений, но не являются
  обязательным требованием одного разговора.
- **Текстовый режим.** Можно начать без микрофона и аватара. Обычный запуск
  всё равно предзагружает STT/TTS; для оценки лёгкого текстового профиля
  отключите обе предзагрузки или используйте безопасный режим. Отдельный
  подтверждённый минимум ОЗУ для такого профиля пока не заявлен.

Интернет нужен для первой загрузки весов и для ответов внешней LLM.
Скачанные речевые модели могут работать локально, но это не даёт Iris
полноценный разговор без сети. Скорость API и качество микрофона влияют
на задержку независимо от CPU/GPU; требования не обещают конкретный P95.
