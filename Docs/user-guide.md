# Руководство пользователя

Iris объединяет текстовый диалог, непрерывный голосовой разговор, память и
необязательный аватар. Речь распознаётся и синтезируется локально; для ответов
используется настроенный внешний API модели. Поэтому доступ к интернету и
пользовательский ключ нужны даже при локально установленных речевых моделях.

Это руководство описывает текущую реализацию. Публичный Windows-установщик
должен отдельно пройти [условия выпуска](release-checklist.md). Запуск из
исходников описан в [эксплуатации](operations.md).
Перед установкой проверьте [системные требования](system-requirements.md).

## Первый запуск

Откройте **Настройки → Система → Обзор** и нажмите **Настроить Iris**. Мастер объединяет ключ
модели, речевые модели и устройства; незаконченный шаг сохраняется.
**Проверить микрофон** показывает входной уровень до 15 секунд без записи,
**Послушать Iris** воспроизводит локальную пробную фразу. Обе проверки
останавливаются кнопкой. Голос можно подготовить позже и начать с текста.

Первый запуск требует интернета для API диалога и загрузки выбранных моделей.
TeraTTS загружается по кнопке напрямую с Hugging Face в выбранную папку моделей;
файлы проверяются автоматически. Ссылки на источник и условия доступны в карточке
модели по желанию.
Оценочные требования и ограничения текущей версии приведены в
[системных требованиях](system-requirements.md) и [статусе проекта](MILESTONES.md).

Те же настройки доступны отдельно:

1. Откройте **Настройки → Система → API-ключи** и сохраните ключ модели диалога.
2. В разделе моделей проверьте готовность распознавания и синтеза речи.
   Первая загрузка весов требует интернета и свободного места.
3. Начните с текстового сообщения. Затем выберите микрофон и устройство вывода
   и включите голосовой разговор.
4. Если нужен аватар, проверьте его запуск и расположение. Он работает отдельным
   процессом Unity; отсутствие аватара не мешает текстовому диалогу.

Ключи хранятся в Windows Credential Manager. `.env` предназначен для
несекретных параметров разработки и не подходит для ввода ключей.

## Разговор

После длительного перерыва при открытии диалога снова появляется экран
с кнопкой **Начать**. По умолчанию граница — час без новых сообщений;
используется настроенный предельный интервал неактивности. Переписка остаётся
в истории, а память Iris сохраняется. Короткая пауза или перезагрузка страницы
позволяют продолжить текущий разговор. Проверка также работает при возвращении
к открытому окну; включённый голосовой разговор и текущий ответ не прерываются.

В голосовом режиме Iris получает непрерывный поток с микрофона и определяет
окончание реплики по паузе и Smart Turn. Можно перебить звучащий ответ:
подтверждённое начало новой речи останавливает воспроизведение и отменяет
старую генерацию. Точность зависит от микрофона, шума и акустики помещения.

Если голос не готов, проверьте модели и устройства в настройках. Для
диагностики полезны события приложения; подробный порядок есть в
[эксплуатации](operations.md#если-что-то-не-работает).

## Память и история

Iris извлекает устойчивые факты из разговора в фоне. Просьба «запомни» и
исправление ранее сказанного обрабатываются отдельно от обычной беседы.
В центре памяти можно проверить, исправить, закрепить или архивировать факт.

Удаление факта из памяти и удаление исходной реплики из истории — разные
действия. «Забыть навсегда» удаляет запись памяти и связанные свидетельства;
исходную реплику нужно удалить отдельно. Режим инкогнито не сохраняет
состояние живого разговора на диск. Подробности — в [памяти](chroma-memory.md)
и [политике конфиденциальности](../PRIVACY.md).

## Поиск и новости

Можно попросить Iris проверить информацию или найти новости. Источники,
прочитанные страницы и результат проверки доступны в истории. Уведомления о
поиске по умолчанию выключены. Если поиск задерживается, Iris может один раз
коротко обозначить ожидание; быстрый ответ обходится без такой реплики.

Бесплатные источники могут блокировать запросы или возвращать неполную выдачу.
Кэшированный ответ не означает новую проверку. См. [поиск и новости](awareness.md).

## Напоминания

Скажите или напишите: **«Напомни завтра в 19:00 проверить сборку»**. Без точного
времени Iris уточнит его. Напоминания создаются через разговор с Iris.
Поддерживаются, например, «23-го в 19:00», «через пять минут» и английские
формулировки. Неоднозначную дату или время Iris уточняет; «завтра в двенадцать
ночи» лучше заменить точной датой и `00:00`. Подтверждение показывает сохранённые
дату, время и смещение часового пояса. Повторяющиеся напоминания пока не создаются.
В **Память → Планы и обещания** можно перенести срок, выполнить или отменить
запись. Действие **Перенести** раскрывает выбор нового срока, который сохраняется
отдельной кнопкой. У напоминаний рядом с датой показан колокольчик.

Iris должна быть запущена, в том числе в трее. Сроки хранятся между запусками;
пропущенные показываются при следующем открытии. Системные уведомления
разрешаются отдельной кнопкой; внутри Iris напоминание доступно и без разрешения.

## Документы и общий поиск

Скрепка рядом с полем ввода принимает один TXT, MD или PDF с текстовым слоем
до 10 МБ, 100 страниц и 150 000 символов. После чтения задайте вопрос текстом
или голосом. Ссылку вида **[D1]** можно открыть в карточке файла; фрагменты
ответа, название файла и ID источников остаются в истории. Сканам нужен OCR,
которого в этой версии нет.

Текст извлекается локально. Подходящие фрагменты отправляются выбранной внешней
модели. Новые записи истории не хранят скрытые копии исходных фрагментов;
сохраняются сам ответ и сведения об источниках. Длинный документ разбирается
по выбранным фрагментам; это не обещание прочитать каждую строку. Автоматически
в личную память содержимое файла не попадает. Оригинал не сохраняется; после
удаления, перезапуска Iris или через два часа файл нужно прикрепить снова,
чтобы открыть исходный текст. Старая история и резервные копии автоматически
не очищаются и могут содержать ранее сохранённые фрагменты.

Кнопка поиска в верхней панели и **Ctrl+K** ищут по истории, памяти, планам и
названиям настроек. Стрелки выбирают результат, Enter открывает точное место,
Escape закрывает поиск. Доступ к входным записям памяти под ответом появляется
только в режиме разработчика: это сохранённые факты из контекста, а не описание
внутренних рассуждений модели.

## Coding Agent

Для Coding Agent нужны работающий Docker, образ среды исполнения и отдельный
API-ключ. Задача выполняется в собственной копии файлов. Перед переносом
результата в проект просмотрите изменения и примените их отдельным действием.
Настройка описана в [Coding Agent](coding-agent.md).

## Резервные копии и выход

В **Настройки → Система → Резервные копии** можно создать, просмотреть и удалить
ZIP-снимки данных, импортировать и экспортировать их. В установленном приложении
доступно восстановление с сохранением прежних данных и перезапуском. Ключи API
в копии не входят. Проверка ZIP отдельно не заменяет проверку восстановления.

ZIP сохраняет базу, настройки и пользовательские словари распознавания и
произношения. Модели и рабочие файлы Coding Agent в него не входят.
Полный состав — в [эксплуатации](operations.md#резервные-копии).

Для полного выхода используйте **Выйти** (**Quit** в английском интерфейсе)
в меню значка Iris в области уведомлений Windows. Закрытие главного окна
тоже завершает приложение; сворачивание оставляет его работающим.
Перед переносом или удалением файлов данных завершите все процессы Iris.
