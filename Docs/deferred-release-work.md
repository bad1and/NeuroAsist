# Отложенные задачи перед публичным релизом

Этот документ — не список текущих блокеров для локальной разработки. Это задачи, которые становятся обязательными только перед публикацией Iris для внешних пользователей.

## REL-001 — Размер установщика с локальным ML-стеком

**Статус:** отложено до публичного релиза.

### Наблюдение

Проверка Milestone 11 собрала Python sidecar `neuroasist-core.exe` через PyInstaller. Его размер составил примерно **2,86 ГБ**. Главный вклад дают Torch, faster-whisper и связанные нативные зависимости.

### Почему это не блокирует текущую работу

Сейчас приложение используется локально и не готовится к публикации в магазине или массовой раздаче. Тяжёлая локальная сборка допустима: она не требует от пользователя вручную ставить Python, а модели и данные уже управляются отдельно.

### Что сделать перед публичным релизом

1. Определить целевой предел размера базового installer-а и поддерживаемые варианты установки.
2. Разделить базовое приложение и необязательные voice/ML-компоненты:
   - базовый backend и UI;
   - STT runtime и Whisper-модели;
   - TTS runtime и голоса;
   - VAD runtime и модель;
   - опциональные avatar assets.
3. Расширить Model Manager до менеджера runtime-пакетов: показывать размер, версию, прогресс, checksum, удаление и восстановление.
4. Проверить cold start, обновление, удаление и offline-поведение каждого варианта.
5. Собрать NSIS installer на выделенной build-машине, затем установить его на чистую Windows VM.
6. Подготовить SPDX/license audit всех поставляемых пакетов и ассетов.

### Критерий готовности

Чистая Windows VM устанавливает базовое приложение без Python/terminal-команд; нужные компоненты загружаются из интерфейса с понятным размером и прогрессом; удаление приложения не удаляет память пользователя без явного выбора.

## Что нужно для запуска сейчас

Для текущего локального режима достаточно существующего рабочего окружения проекта:

1. Python virtual environment `.venv` с зависимостями проекта.
2. Node dependencies для web/desktop части.
3. DeepSeek API key — при запуске Tauri он вводится в первом окне и хранится в Windows Credential Manager; для development-режима допускается `.env`.
4. Для Live voice: в **Settings → Models** скачать Silero VAD. Для STT/TTS могут потребоваться их локальные runtime/model зависимости, заданные текущей конфигурацией.

NSIS, clean VM и оптимизированный installer для локального запуска сейчас **не требуются**.

### Быстрый запуск desktop-версии

Открой PowerShell в папке проекта и выполни одну команду:

```powershell
npm --prefix apps/desktop run dev
```

На первом запуске появится окно Iris. Вставь в него DeepSeek API key и нажми **Save and continue**. Приложение перезапустит свой локальный backend автоматически. Остановить приложение можно, закрыв окно/выйдя через tray или нажав `Ctrl+C` в PowerShell.

Для режима Live разреши доступ к микрофону в окне приложения и в **Settings → Models** нажми **Download** у Silero VAD. Первое использование STT/TTS может занять больше времени, потому что локальные модели подготавливаются на компьютере.
