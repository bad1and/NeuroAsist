# Release work: compatibility link

Этот файл сохранён, чтобы старые ссылки не ломались. Прежнее решение «отложить
installer и clean-VM проверки» больше не является актуальной release policy для
ветки 1.0.

Текущие документы:

- [Release checklist 1.0](release-checklist.md) — обязательные blockers и критерии одобрения;
- [Эксплуатация и сборка](operations.md) — команды build, smoke и диагностики;
- [Текущий статус](MILESTONES.md) — завершённые контуры и открытые gates.

Размер Python/ML sidecar, раздельная доставка voice-компонентов, clean Windows
VM, upgrade/uninstall, restore и license audit теперь считаются открытыми
release gates, а не необязательными будущими задачами.
