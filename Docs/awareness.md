# Поиск и новости Iris

Iris использует бесплатные источники без API-ключей. Поиск скрыт в ходе
разговора; ссылки доступны в деталях ответа в истории, а не в реплике или TTS.

## Веб-поиск

Основной источник — DuckDuckGo HTML, резерв — Bing RSS. Успешный HTTP-ответ
не означает подходящую выдачу: backend проверяет тему, название продукта и
номер версии. Из восьми кандидатов выбираются максимум три; официальные
домены из `preferred_domains` получают приоритет только после проверки темы.

Прямые просьбы найти сведения и вопросы о релизах/текущих версиях запускают
поиск до генерации ответа. Это не зависит от того, решит ли модель вернуть
команду. Короткие уточнения «найди ты»/«ну что там» используют только недавнюю
тему пользовательского запроса; приветствия, правка кода и личные данные не
активируют этот путь. Разговорное «гта шесть» сохраняет номер игры как GTA VI;
упоминание ПК сохраняется в запросе.

В потоковом текстовом и голосовом ответе перед проверкой появляется «Так,
секунду, проверю». Затем тот же ход продолжает ответ, без нового сообщения
пользователя. Речевая фраза проходит обычный TTS-конвейер; служебная команда
не проходит проверки стиля речи и не озвучивается. Avatar-тег перед скрытой
командой допустим. Автоматический путь требует только одного вызова модели
для ответа; модельный путь остаётся для остальных запросов.

Противоречащие даты, включая переносы внутри одного года, вызывают одно
уточнение сразу после первой выдачи. Старое официальное объявление само по
себе не прекращает такую проверку.

Для остальных запросов поддерживаются команды:

```json
{"web_search":{"query":"GTA VI release date Rockstar","fallback_query":"Grand Theft Auto VI official launch","preferred_domains":["rockstargames.com"]}}
```

```text
[[web_search: {"query":"GTA VI release date Rockstar","preferred_domains":["rockstargames.com"]}]]
```

Старые команды с одной строкой запроса остаются совместимыми. Поля уточнения
необязательны. Нельзя передавать в запрос историю, личные данные или память.

За ход разрешён один поисковый шаг, до трёх поисковых обращений и чтение
максимум двух страниц. Общий дедлайн, включая чтение, — пять секунд.
Недоступная страница не отменяет уже найденный сниппет, но ограничение видно
модели. Произвольные страницы ограничены 512 КБ; разрешены публичные HTTP(S)
адреса и стандартные порты. При каждом перенаправлении проверяется новый
адрес; TCP-соединение закрепляется за проверенным публичным IP.

Удачные результаты кэшируются пять минут, ошибки — 30 секунд. После капчи
или 429 провайдер исключается на минуту. Одинаковые запросы объединяются;
отмена одного из нескольких ожидающих не отменяет запрос остальных.

## Новости

15 лент покрывают `general`, `tech`, `science`, `games`; `all` выбирает
события из разных категорий. Ленты включают Google News, РБК, Ленту,
Коммерсантъ, BBC World, Хабр, 3DNews, BBC Technology, Ars Technica,
TechCrunch, N+1, NASA, ScienceDaily, DTF и IGN.

Обновление запускается после готовности текстового чата и обновляет каждый
источник раз в 15 минут. Одновременно загружаются максимум четыре ленты;
таймаут каждой — две секунды. При выключенных новостях новые фоновые
загрузки не запускаются. При завершении приложения задачи отменяются.

Кэш хранит статьи по источникам, поддерживает RSS и Atom. Дайджест
собирается для текущего вопроса: максимум пять событий, два от одного
источника, без дублей. Новости без известной даты и старше 48 часов не
выдаются как свежие. Для вопросов о вчерашнем дне, неделе или месяце
используется соответствующий период доступных лент; архивная полнота
не гарантируется. Недостаток тематических данных вызывает веб-поиск,
если он включён. Устаревший кэш допустим до двух часов и явно помечается.

`GET /environment/news` сохраняет прежние поля и добавляет `updated_at`,
`stale`, `cached`; статьи содержат `url` и `stale`. Метаданные ответов
`web_search` и `news` содержат источники и даты. Поиск также сохраняет
попытки провайдеров, время выполнения и состояние чтения страниц.

## Контекст и проверка

Новости не добавляются в обычную беседу. Новостной дайджест ограничен
900 символами, внешнее обогащение хода — 1600. Последующий поиск заменяет
предыдущую подборку. Ранжирование, извлечение текста и обновление лент не
вызывают LLM. Внешние данные рассматриваются как недоверенный текст.

Детерминированные проверки находятся в `tests/test_awareness_retrieval.py`
и `tests/test_autonomous_web_search.py`; доступность реальных провайдеров
нужно проверять отдельно. Бесплатные поисковые страницы могут менять
разметку и блокировать запросы: при отсутствии свидетельств Iris должна
обозначить неопределённость.
