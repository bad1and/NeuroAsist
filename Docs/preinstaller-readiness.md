# Приёмка Iris перед установщиком

[Документация](index.md) · [Порядок сборки](release-runbook.md)

Этот этап проверяет каталог приложения без NSIS. Успешная сборка и модульные
тесты подтверждают только указанные сценарии. Переход к установщику требует
проверки одного зафиксированного кандидата и решения по правам поставки.

## Реализованные сценарии

- Управление четырьмя голосовыми моделями доступно без режима разработчика:
  закреплённые revisions, размер, прогресс, SHA-256, отмена и повтор.
  Неоконченная загрузка не считается установленной. Удаление через оболочку
  выполняется после остановки ядра; текст доступен до готовности голоса.
- Резервные копии включают SQLite, несекретные настройки и словари. Desktop
  поддерживает импорт, экспорт и восстановление, включая прежние ZIP.
  Проверка архива предшествует замене; журнал позволяет откат после прерывания.
  При ошибке запуска восстановление доступно на стартовом экране.
- Coding Agent работает только с зарегистрированными проектами. Задания
  находятся в пользовательских данных. Docker остаётся внешним компонентом;
  закреплённый образ готовится из ресурсов приложения с отменой и повтором.
- Production-сборка исключает страницы предпросмотра, загружает студию
  по требованию и использует CSP для локального ядра и медиаресурсов.
  Индикаторы используют Anime.js v4 и учитывают reduced motion.
- Подготовка каталога приложения не создаёт установщик. Состав поставки,
  снимок исходников и контрольные суммы сохраняются рядом с кандидатом.

## Карточка кандидата

Запишите версию, commit, снимок исходников, SHA-256 манифеста, Windows,
процессор, память, устройства, свободное место и условия сети. Все последующие
сценарии проверяйте на этом же каталоге. При замене бинарных файлов результаты
проверок затронутых сценариев нужно подтвердить заново.

## Обязательная приёмка

- [ ] Автоматика: полный backend, Vitest, TypeScript/Vite, Rust, документация,
  строгие зависимости CPU-профиля; нестабильные сценарии повторены отдельно.
- [ ] Пустой профиль: нет ключей и весов; текст после ввода ключа, загрузка,
  отмена, повтор, повреждённые веса, отключение сети и недостаток места.
- [ ] Данные: старая схема, новый и прежний ZIP, повреждённый архив, прерывание
  восстановления, очистка истории с сохранением памяти и возврат прежних данных.
- [ ] Диалог: поток, отмена, источники, исправление памяти, ошибки API,
  переподключение; 30 минут с учётом токенов и физических повторов ниже 2%.
- [ ] Голос: час реального разговора, перебивания, смена устройств; измерение
  фактического начала звука, целевой P95 ≤ 2,5 с в прогретом контрольном сценарии.
- [ ] Аватар: оба размещения, длительная синхронизация и отсутствие дочерних
  процессов после выхода; текст при недоступном Unity или микрофоне.
- [ ] Жизненный цикл: второй экземпляр, сворачивание, закрытие, трей, сбой ядра,
  безопасный режим; час синтетического soak с ростом RSS не более 512 МиБ.
- [ ] Coding Agent: Docker отсутствует, подготовка/отмена/повтор, проект,
  выполнение, просмотр, применение и конфликт исходников.
- [ ] RU/EN: пустые состояния, ошибки, клавиатура, небольшое окно, масштаб
  Windows 125–200%, автосохранение и длинные списки.
- [ ] Отдельная Windows-среда: нет инструментов разработчика; каталог приложения
  закрыт для записи, все изменяемые данные находятся в профиле пользователя.
- [ ] Права: аватар именно в составе Iris, Mixamo, Proxima Nova, веса, Unity,
  бинарные компоненты и обязательные notices подтверждены владельцем.

## Исторические подтверждения — 12 октября 2026

Журналы локальной проверки сохраняются в `output/v1-preinstaller` и не являются
отчётом опубликованного релиза. Ранний срез основан на `88bcde77`;
последующий `candidate-persona-20261012` — на `7d15ca2c` с dirty-деревом.
Эти каталоги предшествуют исправлениям 20 октября и не являются финальным
кандидатом нынешних исходников. Точные сведения хранят их собственные манифесты.

Одночасовой синтетический прогон завершён: рост RSS 5,461 МиБ при пороге
512 МиБ, дубли и незавершённые задания — 0. Это подтверждение синтетического
жизненного цикла; реальный голос и задержка воспроизведения требуют отдельного
измерения. Проверка упакованного ядра подтвердила `/health`, авторизованную
остановку и завершение процесса с кодом 0.

Владелец подтвердил разрешение для модели Iris 12 октября 2026 года; документ
нужно приложить к карточке выпуска. Mixamo и Proxima Nova остаются открытыми. Автоматический
перечень лицензий не является разрешением распространения. Существующий аватар
сохранён. [Учёт материалов](../THIRD_PARTY_ASSETS.md) содержит основания проверки.

Аппаратные минимумы остаются оценками до испытания соответствующего компьютера.
После завершения этой карточки начинается отдельный этап NSIS, WebView2,
подписи, установки, обновления, удаления и публикации.
