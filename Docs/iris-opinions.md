# Взгляды Iris

Iris может иметь собственную оценку, спорить, выбрать сторону и обдумать новую тему
по своему характеру. Отговорка «я ИИ, у меня нет мнения» не заменяет ответ.
Мнение остаётся оценкой: оно не подтверждает факты и не требует выдумывать
человеческую биографию. Русская идентичность и позиция за Россию — единственная
исходная запись. Любовь к людям и культуре совместима с честной критикой;
данные поиска и факты не подгоняются под позицию.

## Хранение и пересмотр

Отдельный `iris-opinions.sqlite3` лежит в каталоге данных приложения.
Пользовательские факты, эпизоды, эмоции и мемотека остаются в своих хранилищах.
У каждого взгляда есть тема, синонимы, позиция, причина, источник и версия.
Каждая новая версия добавляется в историю; прежняя не перезаписывается.
Автоматического срока жизни и вытеснения старых взглядов нет; предел — 4096 тем.

Обычные пользователи не видят редактор. Он открывается через режим разработчика
в настройках интерфейса → **Память → Взгляды Iris**. Там можно просмотреть историю,
внести пересмотр с причиной и отключить подсказку. Ручные изменения помечаются
отдельно от записей Iris. Отключение подсказки не переписывает базовый характер.

Взгляд передаётся скрытым полем `opinion` в том же ответе модели. Для live это
заголовок `[[opinion: {...}]]` перед речью. Он удаляется до UI, субтитров и TTS.
Нет отдельного извлечения мнений или фонового LLM-вызова.

Создание использует `id=null, expected_revision=0`. Пересмотр копирует `id` и
**текущую** `expected_revision` из контекста; модель не увеличивает её сама.
SQLite проверяет версию и добавляет новую запись в одной транзакции.
Известную тему нельзя незаметно завести второй раз через прежнее название
или сохранённый синоним. При конфликте сохраняется прежняя позиция.

Изменение фиксируется после проверки ответа. Если модель не признала пересмотр,
backend добавляет явное признание, старую и новую позиции и причину.
Естественное признание модели сохраняется без второго монолога. В live ответ,
содержащий запись взгляда, удерживается до сохранения; его эмоция и жест
сохраняются. Обычный поток без новой записи продолжает работать по частям.
Неудачный ответ, отброшенная попытка и отмена генерации до её завершения
не записывают предложение. Инкогнито и режим памяти `off` приостанавливают
автоматические записи. Ошибка хранилища не перезаписывает старую позицию.

Это структурированная память персонажа, а не гарантия безошибочности модели.
Решение о новой оценке и смысловом пересмотре принимает LLM. Совпадение тем
использует названия, синонимы и лёгкую нормализацию слов; это не полноценный
семантический поиск. Неизвестный синоним может не попасть в выборку, поэтому
история и проверка версии остаются отдельными защитами.

## Контекст и расход

В ответ выбираются максимум три относящиеся к теме позиции в общем лимите
2400 символов вместе с правилами. Для пересмотренной позиции подаются прежняя
позиция и причина изменения. Полный архив никогда не вкладывается в каждый ход.
Короткое продолжение может использовать последнюю тему; новая тема её не наследует.
Приветствия и благодарности обходятся без этого слоя.

Замер закреплённым DeepSeek-токенизатором относительно v13:

| Часть | До | После |
| --- | ---: | ---: |
| Статический live-промпт | 1522 | 1563 |
| Статический JSON с фоновой памятью | 1916 | 1957 |
| Дополнительный контекст без совпадения | 0 | 178 |
| Одна небольшая позиция | 0 | 229 |
| Одна позиция с историей пересмотра | 0 | 279 |

Это токены текста в выбранных примерах, без истории диалога, обёртки API,
эмоционального состояния и ответа. Большие записи расходуют больше в пределах
общего лимита. Основной промпт остаётся в прежних пределах: live 4991/5000,
JSON с устаревшим протоколом памяти 6496/6500 символов.
Диагностика usage содержит `opinion_context_chars`.

## API и проверка

Все маршруты редактора требуют `developer_mode_enabled`; обычный режим получает 403:

- `GET /opinions` — текущие позиции;
- `GET /opinions/{id}/history` — история;
- `POST /opinions` — создание или пересмотр с причиной и `expected_revision`;
- `PATCH /opinions/{id}` — переключение подсказки с текущей `revision`.

Тесты: [test_iris_opinions.py](../tests/test_iris_opinions.py),
[opinions.test.tsx](../apps/web/src/opinions.test.tsx).
Они проверяют перезапуск, гонку двух записей, историю, пропущенную версию,
инкогнито, отключённую память, отброшенные ответы, отмену потока,
разбитые и ошибочные заголовки, сохранение avatar-метаданных и скрытие редактора.

[Сценарий с настоящей моделью](../scripts/evaluate_iris_opinions.py) принимает
учётные данные JSON через stdin и использует временную БД. Он проверяет новую
позицию, перезапуск, давление согласиться, выбор стороны и осознанный пересмотр
в JSON и live. Рабочая история, память, микрофон, TTS и Core не запускаются.
Такой прогон не заменяет проверку настоящего микрофона и озвучивания в desktop.
