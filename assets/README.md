# Iris illustrations

The startup illustrations are release assets exported from the supplied PNGs in
`Для мусора (не удалять)`. Source files stay untouched; the local source folder
is ignored by Git.

| Asset | Source |
| --- | --- |
| `startup-flora-left.webp` | `Акварельные ирисы на прозрачном фоне.png` |
| `startup-flora-right.webp` | `Пурпурные ирисы на прозрачном фоне.png` |
| `startup-flora-left-compact.webp` | `Фиолетовые ирисы на прозрачном фоне.png` |
| `startup-flora-right-compact.webp` | `Пурпурные ирисы на прозрачном фоне.png` |
| `startup-flora-top-right.webp` | `Фиолетовые ирисы на прозрачном фоне.png` |

Desktop exports are 768 × 1024; compact exports are 384 × 512. They retain alpha
transparency, proportional scaling and the existing animation canvas. The full
source artwork fits inside that canvas, anchored to its bottom and illustrated
edge, without cropping flower contours. WebP quality is 92.
The small upper-right accent is a proportional 384 × 384 export, turned toward
the corner in CSS. Its stems continue beyond the top and right viewport edges,
sharing the same Anime.js entrance and gentle sway without an internal cut line.

`apps/web/public/brand/iris-overview-banner.png` is an unchanged copy of
`Нежные ирисы на лавандовом фоне.png`, used as the overview hero background.
